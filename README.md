# gta6-meme-x-01 entry
An entry for make.fun's GTA 6 meme bounty: https://make.fun/bounty/gta6-meme-x-01
The entry is the post on X. POST.json names it, and main.ts hands that file to the grader by copying it from /bot to /output.
Run it the way the grader does: `mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts`
Node 22, standard library only, no network, no wall clock: two runs write the same bytes.
